Support

Need help with Taqweem? Start here.

Getting help

  1. Check the FAQ first
  2. Browse the Wiki for guides and features
  3. If you still need help, email us or open a GitHub issue

Contact

  • Email: info@aqyrix.com
  • GitHub issues: github.com/blacksiptimus/Taqweem-IOS/issues

Reporting issues

When you report a problem, please include:

  • Device model and iOS / Android version
  • App version (Settings → Version)
  • Steps to reproduce the issue
  • Screenshots if applicable

Feature requests

We welcome ideas. Email info@aqyrix.com or open a GitHub issue with “Feature Request” in the title.
